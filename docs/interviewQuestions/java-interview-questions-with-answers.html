2. Why Default & Static methods in interfaces?#

Default methods: Add new methods to an existing interface without forcing every implementing class to implement them.
Static methods: to provide utility methods related to the interface without requiring an implementing class object.

3. What is a lambda expression?#

A lambda expression in Java is a short way to implement the abstract method of a functional interface without writing a separate class or method implementation.

1. Encapsulation

Real-time example: Bank Account A bank account balance should not be directly accessible or modified by anyone. We keep variables private and provide public methods to access or update them.

class BankAccount {

    private double balance;

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}

public class Main {
    public static void main(String[] args) {

        BankAccount account = new BankAccount();

        account.deposit(5000);

        System.out.println(account.getBalance());
    }
}

Output:

5000.0

2. Inheritance

Real-time example: Employee Management System Suppose we have different types of employees: Developer and Manager. Both share common employee properties. Instead of writing the same code in every class, we create a parent class.

class Employee {

    int id;
    String name;

    void display() {
        System.out.println(id + " " + name);
    }
}

class Developer extends Employee {

    void writeCode() {
        System.out.println("Developer writes Java code");
    }
}

class Manager extends Employee {

    void conductMeeting() {
        System.out.println("Manager conducts meetings");
    }
}

public class Main {
    public static void main(String[] args) {

        Developer d = new Developer();
        d.id = 101;
        d.name = "John";

        d.display();
        d.writeCode();

        Manager m = new Manager();
        m.id = 102;
        m.name = "David";

        m.display();
        m.conductMeeting();
    }
}

Output:

101 John
Developer writes Java code
102 David
Manager conducts meetings

Interview points:

  • Code reusability.

  • Parent-child relationship.

  • Achieved using extends keyword.

  • Supports method overriding.

3. Polymorphism

Polymorphism means one thing behaving in different ways. There are two types. A. Compile-time polymorphism (Method Overloading) Real-time example: Payment processing with different payment details.

class Payment {

    void pay(int amount) {
        System.out.println("Cash payment: " + amount);
    }

    void pay(String upiId, int amount) {
        System.out.println("UPI payment: " + amount);
    }

    void pay(String cardNumber, int amount, String type) {
        System.out.println(type + " payment: " + amount);
    }
}

public class Main {
    public static void main(String[] args) {

        Payment p = new Payment();

        p.pay(1000);
        p.pay("user@upi", 2000);
        p.pay("123456", 3000, "Credit Card");
    }
}

Output:

Cash payment: 1000
UPI payment: 2000
Credit Card payment: 3000

B. Runtime polymorphism (Method Overriding) Real-time example: Different payment methods process payments differently.

class Payment {

    void makePayment() {
        System.out.println("Processing payment");
    }
}

class UpiPayment extends Payment {

    @Override
    void makePayment() {
        System.out.println("Processing UPI payment");
    }
}

class CardPayment extends Payment {

    @Override
    void makePayment() {
        System.out.println("Processing Card payment");
    }
}

public class Main {
    public static void main(String[] args) {

        Payment p;

        p = new UpiPayment();
        p.makePayment();

        p = new CardPayment();
        p.makePayment();
    }
}

Output:

Processing UPI payment
Processing Card payment

Interview points:

  • Method overloading = compile-time polymorphism.

  • Method overriding = runtime polymorphism.

  • Achieved through inheritance and method overriding.

  • Parent reference can hold a child object.

4. Abstraction Real-time example: ATM Machine When we withdraw money from an ATM, we only interact with the withdrawal option. We don't need to know the internal implementation of how the bank processes the transaction. We can achieve abstraction using abstract classes and interfaces.

abstract class ATM {

    abstract void withdraw(double amount);

    void checkBalance() {
        System.out.println("Checking account balance");
    }
}

class SBIATM extends ATM {

    @Override
    void withdraw(double amount) {
        System.out.println("Withdrawing Rs. " + amount);
    }
}

public class Main {
    public static void main(String[] args) {

        ATM atm = new SBIATM();

        atm.checkBalance();
        atm.withdraw(5000);
    }
}

Output:

Checking account balance
Withdrawing Rs. 5000.0

Interview points:

  • Hides implementation details.

  • Shows only essential functionality.

  • Achieved using abstract classes and interfaces.

  • Reduces complexity.
