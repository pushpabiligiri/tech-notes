# Java 17 Features

- **Sealed Classes** – Restrict which classes can extend or implement a type.
- **Pattern Matching for `instanceof`** – Test an object's type and declare a matching variable in one step.
- **Records** – Concise data-carrier classes with generated accessors, constructors, and common methods.
- **Text Blocks** – Multiline string literals.
- **Switch Expressions** – Use `switch` as an expression that returns a value.
- **Strong Encapsulation of JDK Internals** – Further restrict access to internal JDK APIs.
- **Helpful NullPointerExceptions** – Provide more detailed messages explaining which variable was `null`.
