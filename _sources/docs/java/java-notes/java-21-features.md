# Java 21 Features

- **Virtual Threads** ⭐ – Lightweight threads designed to simplify high-throughput concurrent applications.
- **Pattern Matching for `switch`** – Match values against types and patterns in `switch` statements and expressions.
- **Record Patterns** – Deconstruct record values in pattern matching.
- **Sequenced Collections** – Provide consistent APIs for collections with a defined encounter order.
- **String Templates** *(Preview in Java 21; not a permanent feature)* – Embed expressions in string templates.
- **Generational ZGC** – Separate young and old objects to improve garbage-collection efficiency.
- **Unnamed Patterns and Variables** *(Preview in Java 21)* – Use `_` when a variable or pattern binding is intentionally unused.
